# Réponses aux signaleurs — exemples

Une réponse part à **chaque** signaleur, quel que soit le verdict.

## Hameçonnage (usurpation, vol d'identifiants ou de paiement) (TCK-0001)

**FR**

```
Bonjour Théo,

Merci pour votre signalement : vous avez bien fait. Ce message est une tentative de vol d'identifiants et fait partie d'une campagne signalée par 19 personne(s). Nous le retirons de toutes les boîtes.

Si vous avez cliqué sur un lien, saisi un mot de passe ou ouvert une pièce jointe, pas de panique, mais prévenez-nous tout de suite en répondant à ce message : plus on agit tôt, plus c'est simple.

L'équipe Sécurité
```

**EN**

```
Hello Théo,

Thank you for reporting this — you did the right thing. This message is a phishing attempt to steal your credentials and is part of a campaign reported by 19 people. We are removing it from all mailboxes.

If you clicked a link, entered a password or opened an attachment, that's okay, but please tell us right away by replying to this email: the sooner we act, the easier it is.

The Security Team
```

## Suspect, à analyser par un humain (TCK-0012)

**FR**

```
Bonjour Manon,

Merci pour votre signalement. Un analyste l'examine et revient vers vous rapidement. En attendant, ne cliquez sur aucun lien de ce message.

L'équipe Sécurité
```

**EN**

```
Hello Manon,

Thank you for your report. An analyst is reviewing it and will get back to you shortly. In the meantime, please do not click any link in this message.

The Security Team
```

## Légitime (faux signalement) (TCK-0064)

**FR**

```
Bonjour Zoé,

Merci pour votre vigilance, c'est exactement le bon réflexe. Ce message est légitime : il vient bien de acme-conseil.atlassian.net, et son authenticité a été vérifiée. Vous pouvez l'utiliser normalement.

Au moindre doute, continuez à nous signaler les messages : nous préférons dix vérifications à un incident.

L'équipe Sécurité
```

**EN**

```
Hello Zoé,

Thank you for being vigilant — that's exactly the right reflex. This message is legitimate: it really comes from acme-conseil.atlassian.net, and its authenticity was verified. You can use it normally.

Whenever in doubt, keep reporting: we'd rather check ten emails than handle one incident.

The Security Team
```

## Exercice de sensibilisation interne (bon réflexe !) (TCK-0063)

**FR**

```
Bonjour Louis,

Bravo ! Ce message faisait partie d'un exercice de sensibilisation, et vous l'avez repéré. Signaler, c'est le geste qui protège le plus l'entreprise.

L'équipe Sécurité
```

**EN**

```
Hello Louis,

Well done! This message was part of an awareness exercise, and you spotted it. Reporting is the single most protective thing you can do.

The Security Team
```
