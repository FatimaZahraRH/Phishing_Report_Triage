## Pourquoi ce verdict
- Expéditeur non authentifié : SPF=none, DKIM=none, DMARC=permerror.
- Adresse d'expéditeur invalide (microsoft account team).
- Les réponses partent vers gmail.com (messagerie gratuite), pas vers .
- Se présente comme « microsoft » mais écrit depuis ?.
- Pression temporelle (urgence, suspension, expiration).
- Promesse de gain (bonus, lot, crypto).

## Objet(s)
- Microsoft account unusual signin activity

## Indicateurs (désamorcés, à bloquer / rechercher)
Expéditeurs : `microsoft account team`

## Procédure
1. Retirer le message de toutes les boîtes (recherche par objet + expéditeur).
2. Bloquer les domaines des liens sur le proxy / filtrage DNS.
3. Chercher dans les journaux proxy/DNS qui a visité ces domaines.
4. Pour chaque visiteur : réinitialiser le mot de passe, révoquer les sessions, vérifier la MFA.
5. Vérifier les connexions inhabituelles sur ces comptes (Entra ID / journaux de connexion).
